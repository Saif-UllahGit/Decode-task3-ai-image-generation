# 🎨 Decode-task3-ai-image-generation

An AI-powered **Image Generation Studio** built with **Python, Streamlit, and OpenAI GPT Image API**.

This application allows users to generate high-quality AI images from text prompts, customize image styles and aspect ratios, preview generated images, save generation history, and download created images through an interactive web interface.

Developed as part of the **Decode Internship Program (Task 3)**.

---

## 🚀 Features

- ✅ AI image generation using OpenAI GPT Image API
- ✅ Text-to-image generation
- ✅ Multiple artistic styles
- ✅ Customizable aspect ratios
- ✅ Generate multiple images
- ✅ Image preview and download
- ✅ Automatic image saving
- ✅ Generation history tracking
- ✅ Interactive Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI GPT Image API
- OpenAI Python SDK
- Pillow
- Python-dotenv
